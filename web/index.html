웨더핏 서울

오늘 날씨에, 지금 열려 있는 곳만 골라 짜는 AI 서울 코스

☀
불러오는 중

      비짓서울 API 데이터를 실제로 수집·정규화해 측정한 값입니다. 제안서의 근거 수치와 동일한 계산을 씁니다.

      범례
      오늘의 행사 (앵커)
      도보권 로컬 음식
      날씨 대비 실내 대안
      그 밖의 통과 후보
      비·폭염일 때 실외 장소는 후보에서 빠집니다.

      이용 안내

      이 서비스가 하는 일

      비짓서울 API의 관광 콘텐츠에 ‘지금 갈 수 있는가’를 판정하는 계층을 얹었습니다. 이미 끝난 행사, 오늘 휴무인 곳, 지금 날씨에 무리인 야외 장소를 걸러낸 뒤 남은 것으로만 반나절 코스를 만듭니다.

      판정 단계

      기간종료된 행사인가
      날씨지금 날씨에 실외를 권할 수 있는가
      운영오늘 휴무이거나 영업시간 밖인가
      거리도보권 안에 있는가

      ‘판정 불가’를 따로 두는 이유

      이용시간이 자유 문장이라 기계가 읽을 수 없는 경우가 많습니다. 모르는 것을 ‘열려 있다’로 처리하면 헛걸음이 생기고 ‘닫혔다’로 처리하면 멀쩡한 후보가 사라집니다. 그래서 탈락과 판정 불가를 구분하고, 근거 탭에서 그 비율을 그대로 보여줍니다.

      데이터

      관광 콘텐츠 비짓서울 API · 행정동 경계 통계청 · 기상 기상청 초단기실황. 기상청 키가 없으면 기본값으로 판정하며, 화면 상단에 출처가 표시됩니다.

      장소를 선택하세요

      지도의 표시나 왼쪽 목록에서 장소를 고르면 판정 근거와 원문 운영정보가 여기 표시됩니다.
